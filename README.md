# FASHION REBORN — сайт бренд-секонд-маркета

Независимый статический сайт FASHION REBORN: HTML + React (in-browser Babel), без сборки.

## Структура
- `index.html` — главная страница маркета
- `market-catalog.html` — каталог вещей
- `brand-market-philosophy.html` — философия маркета
- `brand-market-authenticity.html` — проверка подлинности
- `brand-market-agb.html` — условия участия
- `legal.html` — Impressum и политика конфиденциальности
- `styles.css` + `tokens/` — дизайн-токены
- `site/` — компоненты (ds.bundle.js), страницы (.jsx), стили, локальные React/Babel в `site/vendor/`

## Публикация

Загрузите содержимое этой папки в корень репозитория. Никакой сборки не требуется.
Production-домен: `https://www.fashionreborn.ch/`.
Перед публикацией social-preview изображений добавьте новые assets без старого брендинга.
